# OptiPhoto CLI

Un'applicazione a riga di comando (CLI) in Python per l'elaborazione rapida, il ridimensionamento e l'ottimizzazione delle immagini.

---

## 🚀 Caratteristiche

* **Ottimizzazione rapida:** Riduce le dimensioni dei file immagine mantenendo un'ottima qualità visiva.
* **Elaborazione in batch:** Supporto per il ridimensionamento e la conversione di più file o intere cartelle.
* **Semplice e leggero:** Costruito in Python, facile da configurare e integrare nei propri workflow.

---

## 🛠️ Requisiti e Installazione

Assicurati di avere **Python 3.x** installato sul sistema.
